# Surprise Stash Front-End Application

Surprise Stash is an eCommerce platform for browsing and purchasing products. The app allows users to view products, add them to their cart, and complete their checkout process. The project is leveraging Tailwind and React for the front-end development and React Router for navigation.

## Description

Surprise Stash is an online store that offers a seamless shopping experience. It allows users to explore products, view individual product details, and manage their cart. The platform also provides an easy checkout flow, a contact page for customer support, and a responsive design that works on any device.

## Features

- **Homepage:** Displays all available products with a search bar to filter products by name.
- **Product Page:** Displays detailed information about a single product, including title, description, image, price, discount (if applicable), and customer reviews.
- **Add to Cart:** Users can add products to the cart from the product page.
- **Cart Page:** Displays a list of products in the cart with a total price and a checkout button.
- **Checkout Success Page:** After a successful checkout, users are shown a confirmation message and can return to the store.
- **Contact Page:** A contact form where users can submit inquiries. The form has validation for full name, subject, email, and body.

- **Lookahead Search Bar:** Users can search for products dynamically as they type.
- **Responsive Design:** The application is designed to be fully responsive for all screen sizes.
- **React Router:** Used for seamless navigation between pages.

## Installation

Follow these steps to set up the project locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/Minu321/Surprise-Stash
   cd holidaze
   ```

2. Install dependencies:

   ```bash
   npm install
   ```

3. Start the development server:

   ```bash
   npm run dev
   ```

5. Open your browser and navigate to `http://localhost:5173`.
